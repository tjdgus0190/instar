# 수익 레퍼런스 라이브러리

기획자·마케터는 후보를 낼 때 이 문서의 **패턴**과 **레퍼런스**에서 출발한다.
수치는 공개 발언·보도 기준이며 시점이 지났을 수 있다. 기획에 인용할 때는 웹에서 최신 상태를 다시 확인하고 출처·시점을 남긴다.
새로 확인한 레퍼런스는 이 문서에 계속 추가한다.

---

## 패턴 A — SEO 유틸리티 + 광고 (트래픽형)

검색으로 매일 들어오는 "한 번 쓰고 나가는 도구". 수익은 광고 RPM × 트래픽, 일부는 프리미엄 업셀.

| 레퍼런스 | 구조 | 참고 포인트 |
|---|---|---|
| iLovePDF, Smallpdf | PDF 변환/압축/병합. 무료 + 광고 + 프리미엄 구독 | 기능 하나당 랜딩 하나(키워드별 페이지) |
| Calculator.net, Omni Calculator | 계산기 수천 개, 광고 | 계산기 1개 = SEO 랜딩 1개. 롱테일 장악 |
| TinyWow | 수십 개 무료 파일/이미지 도구, 광고 | 가입 없이 즉시 사용, 도구 수로 트래픽 합산 |
| 국내 글자수 세기·맞춤법·학점/연봉 실수령액 계산기류 | 단일 기능 + 애드센스 | 한국어 키워드는 경쟁이 상대적으로 약한 곳이 많음 |

**한국형 기회**: 연말정산 환급 계산, 퇴직금·실업급여·주휴수당 계산, 연봉 실수령액, 전역일·D-day, 학점 변환, 평수↔㎡ 변환, 맞춤법/글자수(자소서용 바이트 계산).
**주의**: 광고 수익은 트래픽이 쌓이는 데 수 주~수개월 걸린다 → 단독보다 B/C 패턴과 결합 권장. 애드센스 심사에는 콘텐츠 분량과 정책 페이지가 필요.

## 패턴 B — 결과물 단건 판매 (AI/자동화)

입력 → 무료 미리보기 → 결제 후 전체 결과. 1일 서비스의 **핵심 수익 패턴**.

| 레퍼런스 | 구조 | 참고 포인트 |
|---|---|---|
| remove.bg | 배경 제거. 무료 저해상도, 고해상도는 크레딧 결제. 2021년 Canva가 인수 | 무료 미리보기 → 고품질 유료의 교과서 |
| Photo AI, Interior AI (Pieter Levels) | AI 사진/인테리어 생성. 창업자가 매출을 공개적으로 공유(수십만 달러/월 수준 언급) | 1인 운영, 단순 UI, 결과물 자체가 마케팅 |
| HeadshotPro (Danny Postma) | AI 프로필 사진 단건 판매. 창업자가 높은 월매출을 공개 언급 | 명확한 용도(링크드인 사진) + 단건 가격 |
| CloudConvert | 파일 변환, 무료 한도 + 크레딧/구독 | 사용량 기반 과금 |

**한국형 기회**: 증명/프로필 사진 보정, 자소서·이력서 첨삭 리포트, 사주/궁합/작명 상세 리포트(무료 요약 → 유료 상세), 반려동물 사진 → 캐릭터 일러스트, 청첩장/초대장 문구·디자인 생성.
**주의**: AI API 원가 × 무료 사용량이 마진을 잠식하지 않게 설계. 결과 품질이 낮으면 환불·악평 → 미리보기로 품질을 먼저 보여 준다.

## 패턴 C — 디지털 템플릿·자료 판매 (Gumroad형)

한 번 만들고 계속 판다. 운영 부담이 가장 낮다(지속성 최상).

| 레퍼런스 | 구조 | 참고 포인트 |
|---|---|---|
| Easlo (Notion 템플릿) | Gumroad에서 Notion 템플릿 판매, 창업자가 누적 매출을 공개 공유 | 무료 템플릿으로 리스트 확보 → 유료 번들 |
| Gumroad Discover의 스프레드시트·플래너·프롬프트 팩 | 디지털 파일 판매 | 판매량·평점 공개 → 수요 검증에 활용 |
| 크몽 전자책·템플릿 카테고리 | 국내 디지털 자료 판매 | 리뷰 수로 수요 검증 가능 |

**한국형 기회**: 노션 가계부/취준 관리 템플릿, 엑셀 자동화 시트(가계부·재고·급여), 모바일 청첩장/돌잔치 초대장 템플릿, 면접 질문 DB, 업무 문서 양식 팩.
**웹 서비스와 결합**: 무료 웹 도구(패턴 A)가 유입을 만들고, 결과 화면에서 관련 템플릿(패턴 C)을 판매.

## 패턴 D — 바이럴 테스트 + 광고/유료 상세 결과

공유 동기가 강한 결과 페이지가 트래픽을 만든다.

| 레퍼런스 | 구조 | 참고 포인트 |
|---|---|---|
| 케이테스트 등 국내 심리테스트 사이트 | 심리/성향 테스트, 광고 수익 | 결과 이미지 공유 → 재유입 루프 |
| 16Personalities | 무료 테스트 + 유료 상세 리포트 | 무료 결과로 신뢰 → 유료 심화 |
| neal.fun | 인터랙티브 웹 장난감, 광고/후원 | 화제성 → 대량 트래픽 |

**한국형 기회**: 시즌 테스트(신년 운세, 연애 유형, 직장인 유형), 결과 카드 이미지 생성 + 카카오톡 공유, 상세 해설 유료.
**주의**: 트래픽이 스파이크형이라 지속성은 낮다 → 결과 페이지에서 패턴 B/C로 연결해 수익을 남긴다.

## 패턴 E — 저가 구독 마이크로 SaaS

반복 사용 가치가 분명할 때만. 1일 MVP로는 무겁지만 매출 난 서비스의 2단계 진화 방향.

| 레퍼런스 | 구조 | 참고 포인트 |
|---|---|---|
| Carrd | 원페이지 사이트 빌더, 연 수십 달러 저가 Pro | 극저가 연간 결제 → 이탈 낮음 |
| 각종 상태 모니터링·링크 관리 마이크로 SaaS | 월 소액 구독 | 반복 가치(매일/매주 쓰는 이유)가 핵심 |

## 피해야 할 반(反)레퍼런스

- 해지 어려운 자동 구독, 무료라고 해 놓고 결과에서 결제 강제(일부 QR코드 생성기류가 비판·분쟁을 겪음) → 환불·차지백·계정 정지 리스크.
- 유명 서비스 이름을 도메인·제목에 넣는 키워드 사칭.

## 레퍼런스 추가 양식

```
### <서비스명> — <패턴 A~E>
- URL:
- 수익 모델/가격:
- 매출·트래픽 근거(출처, 시점):
- 우리가 가져올 점:
- 확인일:
```
