# 사업자 없이 돈 받는 방법

> 수수료·정산 조건·가입 자격은 자주 바뀐다. 아래는 출발점이며, **연동 전 반드시 공식 페이지에서 최신 조건을 확인**하고 이 문서를 갱신한다.
> 확인일을 함께 적는다.

## 선택 가이드

| 상황 | 1순위 | 이유 |
|---|---|---|
| 한국 사용자 대상, 단건 결제(카드·간편결제) | **페이앱** | 개인 판매 가능, 결제 링크/URL 방식으로 빠르게 연동, 웹훅(feedbackurl)으로 결제 확인 |
| 해외 사용자 또는 디지털 파일 판매 | **Gumroad** | 가입 즉시 판매, 파일 전달·라이선스 키 내장, MoR(해외 부가세 처리) |
| 해외 구독/라이선스 키가 필요한 SaaS | **Lemon Squeezy** | MoR, 구독·라이선스 API, 웹훅 서명 검증 |
| 무료 도구, 트래픽형 | **Google AdSense** / **카카오 애드핏** | 개인 가입 가능, 결제 연동 불필요 |

## 페이앱 (PayApp)
- 용도: 국내 카드/간편결제 단건 판매.
- 연동: 결제 요청 API 또는 결제 링크 → 결제 완료 시 `feedbackurl`로 서버 통보 → 서버에서 판매자 연동 키 검증 후 결과 해제.
- 확인할 것: 비사업자(개인) 판매 한도·정산 주기·수수료, 판매 불가 업종, 디지털 콘텐츠 판매 가능 여부. (미확인 — 공식 사이트 확인 필요)

## Gumroad
- 용도: 템플릿·전자책·파일, 해외 단건 결제.
- 수수료(2026 기준 보도): 직접 판매 10% + $0.50, Discover 마켓 경유 30%, 별도 결제 처리 수수료 가능. 최소 출금액·보류 기간 존재.
- 연동: 상품 페이지 링크/오버레이, 결제 확인은 Ping(웹훅) 또는 License Key API.
- 한국 계좌 출금 가능 여부·최소 출금액은 공식 Help Center 확인.

## Lemon Squeezy
- 용도: 구독, 라이선스 키, 해외 결제. MoR이므로 해외 세금 처리를 대행.
- 연동: Checkout 링크 + 웹훅(HMAC 서명 검증 필수).
- 가입 심사가 있을 수 있음 → 1일 배포 일정에 걸리면 Gumroad로 대체.

## 광고
- **Google AdSense**: 사이트 심사 필요(충분한 고유 콘텐츠, 개인정보처리방침, 정상 동작). 심사 기간 동안 배포는 먼저 하고, 승인 후 슬롯 활성화.
- **카카오 애드핏**: 국내 트래픽에 적합. 매체 등록·심사 조건은 공식 사이트 확인.
- 광고 배치는 정책 준수(오클릭 유도 금지, 콘텐츠 가림 금지). 위반 시 계정 정지 = 전 서비스 광고 수익 소멸.

## 결제 구현 원칙 (공통)
1. 클라이언트 리다이렉트만으로 유료 결과를 열지 않는다 — 서버 웹훅 검증 후 기록, 기록 기준으로 해제.
2. 주문 ID ↔ 결과 ID를 매핑해 결제 후 재방문해도 결과 접근 가능(이메일 링크 등).
3. 환불정책을 결제 버튼 근처에 링크.
4. `checkout_click`, `purchase` 이벤트 측정.

## 세무 메모
- 사업자 없이 받은 매출도 소득 신고 대상이 될 수 있고, 계속·반복적인 판매는 사업자등록 의무가 생길 수 있다.
- 월 매출이 꾸준히 발생하기 시작하면 CEO가 세무 상담을 안건으로 올리고, 사업자 전환(간이과세자 등) 시 자체 PG·스마트스토어 등 선택지가 넓어진다.
